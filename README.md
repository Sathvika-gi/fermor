# Fermor Homepage

A responsive Fermor homepage built with Next.js, React, TypeScript, and Tailwind CSS.

## Getting started

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

## Design decisions

- **Clarity before complexity:** The page introduces Fermor as a calm financial guide rather than another data-heavy dashboard.
- **A focused visual language:** Deep purple, warm neutrals, strong typography, and restrained geometric details create a trustworthy but distinct identity.
- **Product-led storytelling:** The account overview, next-best-action card, and adjustable goal planner demonstrate how the product helps people understand and act on their finances.
- **Useful interaction:** Visitors can hide their balance, change the chart period, adjust a financial goal, and use the responsive mobile navigation.
- **Responsive by default:** Layouts, typography, navigation, dashboard elements, and cards adapt across desktop and mobile breakpoints.
